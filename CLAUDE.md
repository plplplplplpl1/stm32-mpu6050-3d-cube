# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

STM32F103C8T6 + MPU6050 (6-axis IMU) + SSD1306 OLED (128×64) — real-time 3D attitude display. Rotate the dev board, the wireframe polyhedron on the OLED follows. Supports 31 shapes from Platonic solids to 4D polytopes.

## Build System

- **IDE**: Keil MDK uVision 5 (`Project.uvprojx`)
- **Compiler**: ARMCC V5.06 update 5 (build 528)
- **Optimization**: `-O1`, C99 mode
- **Preprocessor define**: `USE_STDPERIPH_DRIVER`
- **Include paths**: `.\Start;.\Library;.\User;.\System;.\Hardware`
- **Device Pack**: `Keil.STM32F1xx_DFP.2.2.0`
- **Startup file**: `Start/startup_stm32f10x_md.s` (medium-density, STM32F103C8)
- **Output**: `.\Objects\Project.axf`; HEX not generated by default

Build from command line via the `/build-keil` skill or open the `.uvprojx` in uVision and press F7.

## Architecture — Layer Model

```
User/          main.c, Attitude (complementary filter), Cube3D (3D/4D render)
Hardware/      MPU6050, MyI2C (software I2C), OLED (SSD1306), Key, LED, FontCN, Menu
System/        Delay (SysTick-based μs/ms delay)
Library/       STM32 Standard Peripheral Library V3.x (SPL) — full set
Start/         CMSIS core_cm3, stm32f10x.h, system_stm32f10x, startup .s
```

## Two I2C Buses — Critical Design Decision

| Bus | Driver | Pins | Device | Speed |
|-----|--------|------|--------|-------|
| Hardware I2C1 | STM32 I2C peripheral | PB6 (SCL), PB7 (SDA) | OLED SSD1306 | 100 kHz |
| Software I2C | Bitbang (MyI2C) | PB10 (SCL), PB11 (SDA) | MPU6050 | — |

**Do NOT switch which I2C drives which device** without verifying timing: the software I2C has μs-level delays tuned for MPU6050; the OLED uses the SPL hardware I2C driver.
