# W25Q64 读写异常诊断报告

2026-06-10

## 现象

| 操作 | 结果 |
|------|------|
| JEDEC ID 读取 (0x9F) | 正常，返回 EF 40 17 |
| 状态寄存器读取 (0x05) | 正常，SR=0x00 |
| Write Enable (0x06) | WEL 位始终为 0 |
| 扇区擦除 (0x20) | 静默失败 |
| 页编程 (0x02) | 静默失败 |

**结论：W25Q64 能读不能写。**

## 硬件连接

| W25Q64 模块 | STM32 (原) | STM32 (新) |
|-------------|-----------|-----------|
| VCC | 3.3V | 3.3V |
| GND | GND | GND |
| CS | PB12 | PB12 |
| CLK | PB13 | **PB3** |
| DO (MISO) | PB14 | **PB4** |
| DI (MOSI) | PB15 | **PB5** |

模块为 6 脚引出（VCC, GND, CS, CLK, DO, DI），WP/HOLD 未引出，模块 PCB 上已拉高。

## 已尝试方案（全部无效）

| 序号 | 尝试 | 结论 |
|------|------|------|
| 1 | SPI Mode 0 (CPOL=0, CPHA=0) | 读正常，写失败 |
| 2 | SPI Mode 3 (CPOL=1, CPHA=1) | 同上 |
| 3 | SPI 速率: 72M/8=9MHz | 同上 |
| 4 | SPI 速率: 72M/32=2.25MHz | 同上 |
| 5 | CS 前后加 NOP 延时 | 同上 |
| 6 | Write Enable 后加 WEL 等待 | 同上 |

## 当前尝试：SPI1 重映射

SPI1 是独立外设（APB2, 72MHz），和 SPI2（APB1, 36MHz）不同。
通过 GPIO 重映射将 SPI1 映射到 PB3/PB4/PB5，禁用 JTAG 保留 SWD（ST-Link 不受影响）。

## 如果 SPI1 也不行——备选方案

### 方案 A：软件 SPI（推荐）

- 纯 GPIO 翻转，不用 SPI 外设
- Timing 完全可控，100% 可靠
- 缺点：速度慢（~100kHz），写 116KB 约需 10 秒
- 不需要改接线

### 方案 B：换 W25Q64 模块

- 当前模块可能存在个体问题
- 换一块新的测试

### 方案 C：放弃外部 Flash

- 128KB 片内 Flash 仅用 ~21KB，空间充足
- 校准数据改用备份寄存器存储（掉电保持）
- 猫动画/图形数据保留在 Flash 中（Flash 未溢出）

### 方案 D：外挂编程器

- 用 CH341A 等独立 SPI Flash 编程器烧录镜像
- STM32 端只读不写
- 需要额外硬件

## 实施优先级

1. **SPI1 重映射**（当前）→ 下载即测
2. **方案 A：软件 SPI**→ 慢但必定工作
3. **方案 B：换模块**→ 排除硬件个体差异
4. **方案 C：回退**→ 不用外部 Flash
